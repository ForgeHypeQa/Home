# ForgeHype

Website design and digital growth consultancy in Doha, Qatar.

Static site, deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

- `index.html`, `about-forgehype.html`, `faq.html`, `privacy.html`, `terms.html`, `services/*.html`: the pages
- `assets/`: styles, scripts, images, video
- `remotion-films/`: source for the six-problems and fix films (Remotion); see its README to re-render

v1.0, launched October 2026.
